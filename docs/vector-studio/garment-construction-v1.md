# Stage 6 — independent garment candidate

## Contract
Optional strict GarmentDesignV1 on the existing character definition, no changes to solved skeleton, pose, prop ownership or legacy wardrobe. Versioned designs import/export as JSON. Existing shirt/pants/shoe colors are base channels; accent, outer, sole and lace colors are independent. Templates: shirt, blouse, hoodie, tunic, dress; trousers, shorts, leggings, skirt, no bottom; jacket, coat, no outer; sneakers, boots, loafers, bare feet. Templates are parametric candidates sharing a compact geometry generator, not professional garment model sheets. Garments opt in; imported artwork retains slot priority. Existing swimwear/shirtless modes are unchanged.

## Fit and layers
Four fit classes, anatomical shoulder, torso, hip and limb widths, skirt length and hem, sleeve coverage/cuffs, neckline, collar, seams, pockets, buttons, zipper, graphic logo, pattern scale/opacity, sole and lace detail. Independent sleeve panels follow the actual solved shoulder/elbow/wrist; trousers follow actual hip/knee/ankle, with bounded overlap, bend-derived fold paths and waist compression. Inner first, open jacket side panels reveal inner on front views; rear panel remains closed. Pixi fabric fills use a path-local repeating texture; SVG pattern fills use the same silhouette, which confines paint without separate unbounded overlays. Pattern texture appearance is approximate between renderers. Logo is a simple vector emblem, not arbitrary uploaded logo masking. Legacy wardrobe assets remain available in original renderer. Skin/garment coverage at extreme poses needs visual inspection; native preview remains approximate in arm ordering and seated skirts. Shoes anchor at existing foot and fixed sole baseline.

## Stage 9 handoff
GarmentPhysicsV1 validates per-template pin names and weight 1 at calibrated rig landmarks; coarse free hem/cuff three-point rest groups, influence weights, material stiffness/damping/wind/displacement, body capsule proxies. Rest metadata derives from persisted design and rig identity, never saved transient pose velocity. No runtime solver, collision resolution, cloth drape, strand or mesh simulation. Actual seam rest cages and compression shapes need calibration before simulation. Fit templates never alter rig endpoints.

## Gate
Added five profiles × five views × four fits × four pose samples, template/serialization, pivot/prop invariants, and actual IndexedDB/backup regression checks. Extended browser fixture for garment comparisons, native SVG and offline project export; must run and inspect. Do not interpret finite path tests as clipping or artistic approval. Remaining library expansion: differentiated dress cuts, traditional cultural garments, tailored coats, realistic sitting drape, garment-specific authored view artwork, arbitrary masked decals, custom materials, full pattern parity and GPU path caching. No merge until cumulative stage gates are met.
