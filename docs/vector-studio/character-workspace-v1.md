# Stage 11 — Character workspace

Character Factory reuses current canonical CharacterDefinition and renderer, existing artist controls, asset contracts and identity import/export. New drafts start with the explicit Sbu Vector Studio preset (new ID/name); existing characters are not migrated. Identity contains original and flagship preset cards, deterministic seed and group selector, lock toggles, import/export. Body profiles reset proportions and filter incompatible imported parts by declared profile; undo restores prior draft. Face/Eyes/Brows/Nose/Mouth/Ears/Hair/Facial hair/Garments/Footwear/Accessories progressively disclose existing controls. Voice metadata optional, no mandatory hosted service. Physics and Advanced art retain existing panels. Palette controls stay contextual. Randomization is deterministic, curated for common clothing, respects existing locks and imported components; imported art can override native picks, no guarantee all combinations are artistically compatible. Dress excludes bottom garment in randomization; manual legacy/garment choices still have original precedence.

32-entry immutable draft history, same-key edits within 350 ms coalesced, unrelated edits and reset distinct. Undo/redo buttons plus Ctrl/Cmd+Z/Shift+Z outside native input text editing. Save validates canonical schema, duplicate receives new ID; existing local project save and backup path unchanged. No automatic cloud or AI. Preview defaults paused, draws at most once per animation frame on dirty inputs, up to 20 fps when playing and not hidden. Immutable audition scene memoized, idle/dialogue leave unclaimed behavior channels, real evaluator/renderer used. Zoom .6–3x CSS transform and drag/arrow pan, fit resets viewport without changing rig or physics; this is not a high-resolution rerender at every zoom. Thumbnail SVG glyph cache bounded 192 entries with relevant appearance keys, hair model cache reused; no full per-part dirty Pixi tessellation or persistent thumbnail disk cache. Live draw still redraws actor geometry; expensive sliders coalesce rendering per frame rather than delaying visible controls. SVG fallback supports approximate static/animated audition but not LVE/lighting equivalence.

Temporary physics Off/Subtle/Expressive and wind only affect audition scene. Character material/strength overrides are saved explicitly, not audition settings. Optional webcam opens existing consent-based Performance Studio; camera only enabled via its explicit button. Preview-only disables mic/audio storage and motion-style apply; recorded pose returned as ephemeral clip, no project mutation. Actual camera hardware and nested dialog interaction not yet certified. Closing/unmount uses existing media cleanup. Scene auditions use same pipeline and timeline action semantics, but no promise of pixel-identical camera/scale/layout with a different scene; audio is not played in the character factory. Run browser QA, verify saved project offline and check backup roundtrip. Real device responsiveness, professional artwork, complete renderer parity, actual webcam and production audio export remain open. No release until consolidated acceptance.
