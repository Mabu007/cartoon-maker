# Special stage — VVLE foundation
Opt-in scene.visual.volume v1; existing legacy lighting unchanged when disabled. Use the existing Environment Controls > Lighting & perspective > Environmental lighting > Volumetric vector lighting; select a cinematic setup, or configure existing local lights. Edit lights & ground supplies the pre-existing draggable and keyframed handles. Setup selection explicitly replaces old light keys. Ambient plus directional, point, spot, fill and rim light descriptors, elevation, color, intensity, radius, falloff, cone, softness. Interrogation, candlelit, night street, daylight and portrait setups. Exposure/contrast/saturation affect evaluated surface colors, not a final-image color grading pass. Depth haze is approximate, not depth-of-field blur.
Analytic local ellipsoid normal samples, Lambert/soft diffuse, approximate half-vector specular, material coefficients skin/hair/fabric/leather/metal/glass, edge AO and rim. Pixi built-in local gradient fills (five quantized stops, 32-pixel gradient texture, 16 directions, per-renderer bounded 128 entry cache, dispose unused after frame). No custom shader/normal texture atlas, true per-pixel normals, physically accurate shadows or ray tracing. Base head/illustrated anatomical limb contours, layered hair fills and modular garment paths receive gradient shading. All sampled from existing actor transform and solved geometry, no IK edits. Imported artwork, legacy torso/limbs, small facial features, hands, accessories, held props and native SVG are not full volumetric surfaces. Prop material response is coarse tint. Contact shadows remain legacy plus directional displaced ellipse; no actual occluder shadow map. Backdrop parallax and existing perspective/depth ordering reused, not full multiplane authored environment. Depth haze approximates separation; selective DOF, whole-frame grading, authentic normal authoring, face/hand shading, multi-light per-pixel response, smooth gradients without quantization pop, proper mirrored head normals, exposure and shadow consistency and real environmental occlusion require consolidation.
Eco/balanced/high sample at most 2/4/8 lights. Gradient cap falls back to a solid evaluated color. No AI or runtime network dependency; same renderer for preview/export. CPU and GPU performance NOT measured on N4020. Tests cover schema, preset, material and sample clock; browser harness adds flat versus five setups and moving light screenshots/timing. No visual artistic acceptance until actual captures reviewed. Klaus-inspired artistic direction is a target, not a claimed equivalence.
