# Stage 5 — layered vector hair, development candidate

Stage 5 builds on PR #46 (2fb2f4b); its Vercel preview is READY. Stage 2 professional benchmark and prior release/visual gates remain open. The owner requested isolated development through Stage 5.

## Initial library
Implemented candidate geometry for bald (empty), fade, buzz, short afro, afro, curls, puff, cornrows, braids, box braids and locs. Existing names preserve their legacy renderer until opting into HairDesignV1; the three new names select the new model automatically. Unsupported styles retain their previous implementation. Expansion: short 360 waves (legacy waves means long wavy hair), twists, Bantu knots, straight hair and gathered ponytails/buns, plus more distinct professional variants. No style is visually certified.

## Geometry and metadata
Canonical typed vector regions in head-local rig units; shape-aware cap, hairline, side panels, grouped lock strokes, texture and accessory layers. Rear views show a closed crown; profile hides the far chain set; three-quarter views use head projection offsets. Mirroring uses the existing actor/head transform. Imported hair/closed hats override the new engine. The background group draws before skull and ears, foreground before facial details; long locks are not split behind the torso container yet. Exact native fallback/body/hat/ear parity remains incomplete.

HairDesignV1 saves dimensions, hairline, density, braid thickness, parting, highlight strength and material stiffness/damping/wind/max displacement; hairColor is the existing semantic base palette. Anchor positions and rest chains/cages are derived deterministically from the saved version, view and head metrics, not duplicated in the character. Generated canonical artwork (including root anchors, per-control-point pin/influence, material/control-group refs and collision proxies) is serializable. Groups carry root pin, sparse rest points and approximate head/shoulder proxy refs; these proxies are rest authoring hints, not collision detection. Rigid styles have no dynamic groups. Afro/puff bounded max 3 rig units, locks max 10. Manual audition displaces canonical points by pin/influence, not physics and not collision resolved. No animation runtime state is saved.

## Cache and gate
48-entry bounded immutable model cache keyed by hair/shape/view/appearance and material fields; weak rest descriptor cache, existing bounded GraphicsPath parser cache. No per-strand simulation or network. No GPU tessellation cache or device timings claimed. Tests exercise all styles/views at parameter extremes, strict vector roundtrip, fixed roots, displacement clamps, cache invalidation, legacy opt-in, and device/backup persistence. Browser captures, both-orientation motion review, real hair ordering/attachment, offline export and target performance remain required. Stage 9 should consume derived groups as actor-local rest data with solver-owned runtime state and collision tests. Stage 6 can use the same head/root and shoulder authoring references but must calibrate actual garment/rig contact.
