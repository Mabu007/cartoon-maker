# Stage 7 — primary deformation candidate

## Authority and interface
The timeline evaluator, recorded-performance sampler, motion intent, stabilizer, strict captured-arm IK, contact corrections, hand/thumb channels, view selection, gaze and visemes remain authoritative. The original arm/leg endpoint code was extracted (not redesigned) to resolvedArtworkPose.ts. Pixi consumes those helpers and SVG factory audition uses them for its synthetic action pose. No raw landmarks are re-targeted by artwork. Renderer RenderOptions.onResolvedArtworkPose optionally delivers a detached actor-local snapshot of final arm/leg positions, head transform before global lift/mirroring, selected view/head view, near arm, hand geometry/scale/rotation/contact occupancy, facial performance, action, locomotion and time. Consumers must not re-solve pose. Callback allocation only when requested; no new saved runtime state. Existing gait blend behavior is retained, including its approximate blended lengths; do not claim all gait lengths are mathematically exact.

## Art
Optional CharacterVisual.primaryArt=pose-v1, enabled on explicit Vector Studio upgrades; original anatomical and classic styles unchanged. Bounded quantized transverse control point compression for native upper arm, forearm, thigh, calf; preserve axial coordinates and command topology, shared outline/shadow/highlight, existing overlapping seam contours. 96-entry FIFO pose contour cache, existing 64-entry morphology cache and existing Pixi path parser; no GPU tessellation cache. Classifier reads already solved joints plus contact, confidence and projected chain length; optional previous class hysteresis is available for sequential clients, but renderer uses stateless class for deterministic seek/export. Existing view/depth hysteresis and captured near/far paint order are reused, no independent animator. Explicit poseArtwork variants replace full normalized bone artwork by class and orientation; unmatched pose returns base. Incompatible topology is not interpolated. Native component import JSON can carry these variants; no visual variant authoring UI. Actual calibrated pose model sheets and full skin seam mesh remain unfinished. Shoulder/neck/torso/hip/wrist/ankle refined surface shapes, true projection depth and joint deformation, full native hand/face parity and exact depth for authored gestures remain consolidation work.

## Garment follow-up
Wrap tunic and wrap skirt are generic culturally adaptable construction primitives, not verified representations of any named cultural dress. Seated skirt takes solved knee positions for bounded drape and support; not cloth simulation and not a guarantee of no clipping. Existing uploaded logo is fit inside a small chest badge rectangle (Pixi bounded aspect-fit decal, SVG explicit rectangular clip), not arbitrary contour masking, pattern warp or decal mesh. Rear hair tracks global actor lift in same order as face. Garment template art quality, sleeve/torso occlusion, layered dress seated drape, full pattern matching, authored garment view art and visual proof still require review.

## Proof
Automated tests for all five views, two characters, exact captured arm bone lengths/held anchors, representative action samples and immutable inputs, contour topology/axial coordinates, bounded cache, confidence/classification/hysteresis, alternate topology selection, recorded take with tracking loss and seated wrap shape. Existing full regression suite must pass; real browser screenshots, audio export, webcam and device timing are separate gates. Runtime secondary dynamics remain Stage 9 only. Do not treat authored tests or a successful static build as visual acceptance.
