# Stage 8 — isolated Living Vector Engine
Opt-in library only; no character runtime switch, no changes to timeline, pose solver, prop custody or export path. Uses local rest points and an externally sampled primary affine transform at integer ticks (translation inertial acceleration; world forces transformed by inverse linear part). Units: actor-local rig units, seconds, velocity units/s, acceleration units/s², mass relative units, stiffness mass/s², damping mass/s, drag 1/s, impulse velocity delta; provisional artistic constants rather than SI cloth properties. Seeded hash noise per tick/entity/node. Fixed 30/60 Hz; damped semi-implicit springs and position-based distance constraints (bend represented as skip-link distance), capsule/circle collision, bounded displacement and velocity. Pin=1 locks rest, partial pins cap travel and scale mobility. Stable ID order; distance/bend constraints sorted by kind and endpoints; collision then bounds (infeasible collision can retain penetration). No iterative high-resolution cloth. No 3D.
Default scene budget 192 nodes, 48 per actor, 384 constraints, 4 iterations; whole over-budget entity returns rest. 16 checkpoints at 60 tick intervals, exact revision/config/definition signature, validated restore, deterministic seek replay within 180s, bounded realtime advance 1–8 ticks without dropping time; render interpolation distinct, restore does not reconstruct previous-tick interpolation history until next tick. Reset on cut, sleep, singular transform, teleport >80 world units per tick; invalid input rest fallback. Anchor rotations/scaling are used to transform forces but rotational acceleration is not yet modeled. Input sampler must be pure and versioned; invalidate when upstream edits occur. Checkpoints ephemeral; no project state persisted. Canonical vector deformation via lveRegionCommands, preserving source and existing pin weights. Fixtures: spring, pinned braid, six-point fabric strip and capsule. Node QA script reports CPU tick timings, not hardware/GPU timings. Future Stage 9 must wire actual assets, pose clock, checkpoint ownership, edit invalidation and preview/export identical quality; verify collision feasibility, settling, long-scene budget, browser harness and hardware. No claim of live cloth simulation.
