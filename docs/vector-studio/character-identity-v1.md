# Stage 3 — identity and morphology candidate

Development only, stacked on Stage 1 a41aef8. Stage 2 art benchmark remains unimplemented. The owner requested parallel staged development followed by cleanup after Stage 5; this is not a waiver of release gates.

## Identity
The existing CharacterDefinition remains the single serialized identity. Its original fields already carry face, skin, wardrobe, eyes, hair, voice, personality and embedded artwork. The optional identity metadata adds version 1, unsigned 32-bit seed and unique randomization lock groups. Missing identity is never materialized on legacy read. Explicit character file import accepts legacy raw CharacterDefinition or versioned sirvibe-character envelope; future versions reject. Import replaces a draft while retaining its ID; duplicates deep-copy and use a fresh ID. No transient pose or solver state is stored. Locks affect only seeded randomization, not manual edits or explicit preset changes; independent PRNG streams per group mean toggling a lock does not affect other groups. Hosted voice references are retained.

## Morphology and landmarks
Existing fields remain authoritative: height, head, neckLength, torso, arms, legs, thickness; visual shoulder/waist/hips and widths; bodyBuild chest/hips; handSize and footSize. Added lean, heavyset and petite profiles without removing legacy names. Asset profile compatibility remains explicit; new names may detach old imported parts when not declared compatible. Abdomen multiplies the existing belly contour factor in Pixi wardrobe drawing. Native anatomical contours opt into bounded wrist, knee, ankle, muscle and softness settings. The cached control-point shaping preserves x coordinates, topology and joint centers and changes silhouette/shade/highlight together. Cache keys include relevant quantized fields per region; limit 64. Native custom slots keep their source artwork. No new IK or gait algorithm. Existing rig/visualRigAnchors supplies fit landmarks in all five view families and retains arm and leg lengths; no claimed independent finger length or custom asymmetric views. Native SVG uses shaped limb contours, but its torso is still approximate; abdomen parity is outstanding. Muscle/softness only shape the native anatomical limbs, not full-body anatomy.
