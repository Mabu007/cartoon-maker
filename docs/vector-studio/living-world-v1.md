# Stage 14 — living world

Opt-in Scene.visual.world and Prop.worldArtwork fields. No migration or removal of legacy raster/native assets. Four representative vector sets: living room, township street, shop, podcast studio; use the current scene's environment as fallback. Native vector layers use Stage 1 geometry, semantic palette, bounds, anchors and weighted material. Shared v2 native envelope variant uses worldPacks (not character packs), same bounded JSON preflight and VectorArtworkV1; no archives, resource loading, dependencies or arbitrary SVG. Explicit preview and confirm in Lighting & perspective > Living world. Export set/prop as .sirvibe-assets; geometry and source copied into project backups. Set application preserves actors, props, clips, lighting and existing background image. Ground polygon may be applied separately. Native prop controls under Depth & scale animation support cup, book, phone, table, counter and plant. Legacy seats, doors, raster and other props preserve renderer/contact semantics. No new geometry-based collision solver; furniture surfaces metadata descriptive, actual interaction anchors still existing prop system.

World layer placement uses world coordinates, scale, rotation, depth, optional perspective and lighting. Background below actors (hidden if custom raster background), midground shares depth sort, foreground occludes actors. Built-in scene artwork palette and optional existing lightAt tint; current VVLE applies to actors and regular props; no true world normal shading, rim or cast shadow geometry beyond existing renderer. Fixed static layers cached per renderer, moving geometry redraws only when quantized group offset changes. Removed graphics destroyed. Sparse decoration supports curtain, flag, branch, hanging sign/light, plant. Only one or two chains per asset, 2–5 points, pinned first point, weighted path control handles, material bounds. World solver separate 24/48-node cap, 30/60Hz, 2/4 iterations; actor budgets unchanged (total economy up to120 nodes). Decorative art never moves root, contact anchor or timeline state. Held props are excluded/slept in world solver and rendered at existing hand attachment in rest pose; existing release determines world position. No prop dynamics on legacy seats or doors. Static prop palettes support base channel overridden by existing prop color.

Shared sceneForces samples global wind X/Y, deterministic timeline gusts, gravity and up to eight smooth circular local regions. Both character/world solvers use same world coordinate sampler; actor sample at resolved root, layer at placement, prop at resolved root. For opt-in world scenes character physical orientation uses authored actor view rather than camera view; renderer projection may differ from physical orientation, but camera changes do not drive solver. Existing legacy scenes keep prior camera-dependent physical orientation. No dense fluid/foliage physics or new collision/ground contacts. Paused arrangement shows rest geometry. Local gravity/forces are visual only. WorldSet includes ground polygon and surface metadata; surface metadata does not replace authored interaction. No automatic shop furnishing or new world reusable IndexedDB library; built-ins reusable and imported files portable, embedded directly after confirmation. No AI world specification yet; Stage 13 character prompt accurately notes separate world envelope.

livingWorldAudition reuses existing two-character scene, sit/cup, camera cuts, walk and release, adds native furniture/plant/held artwork and shared wind. Browser script captures before/after/recording, seek equality, solver metrics; unit tests validate schema, hostile input, pins, force coordinates, primary custody, backup and CPU. Actual visual coherence, offline app reopen/video/audio export and N4020 remain separate acceptance gates. Stop after Stage 14.
