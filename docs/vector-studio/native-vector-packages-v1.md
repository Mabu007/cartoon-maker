# Stage 12 — Native vector packages (envelope v2)

The existing raster .sirvibe-assets v1 contract and library remain unchanged. Native v2 accepts only plain JSON, no archive, compression, raw SVG, resource fetch or executable input. UTF-8 byte limit 2 MB; lexical depth 32 and 180k token budget before JSON.parse; aggregate component 24, packs 12, commands 8192, points 16384, simulation nodes 96, constraints 128. Per-artwork Stage 1 budgets still apply. Native package references use stable id + exact revision; all transitive dependencies included. Duplicate references, missing revisions and cycles fail. Atomic IndexedDB installation never overwrites existing revisions; identical dependencies can be reused. Maximum installed 120 revisions and 12 million serialized characters. Removal blocks dependent revisions. Export includes closure. Projects copy canonical geometry and license/provenance source metadata, including simulation definitions; project backups do not require the reusable library. Library entries unused by a project are backed up separately by export.
